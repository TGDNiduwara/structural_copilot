PHASE 2 CLOSEOUT - COINCIDENT-NODE AUDIT (2026-08-23)
================================================================

ROOT-CAUSE DISCOVERED (live, COINC_probe_roundtrip.py):
  Robot's SOLVER MERGES coincident-but-distinct nodes during Calculate().
  A 35-node composed F2 model solved to a 25-node live model; the
  merged-away ids are exactly the coincident pairs. This is the underlying
  mechanism of the whole class: bar_uniform records on bars incident to
  merged-away nodes are dropped (the original 15.68% shortfall), and
  export_structure_spec round-trips are lossy after a solve.

FIX AT THE SINGLE CHOKEPOINT:
  * geometry_primitives.merge_coincident_nodes() (PURE) merges distinct
    nodes at identical coordinates up front, rewriting bar endpoints /
    supports / nodal-load references.
  * _compose_finish applies it: compose-built specs NEVER contain
    coincident nodes -> identical to what Robot will analyze -> no solver
    merge, no load loss, lossless round-trip.
  * apply_nodal_load now FAILS LOUDLY on a nonexistent node id (was a
    silent no-op: a load on a merged-away id gave 0 reactions).
  * Offline regressions: test_compose_copy_then_bracing_no_id_collision
    (copy op advanced next_id past nodes only -> a following bracing op
    collided with copied chord bars - FIXED), test_merge_coincident_nodes.
